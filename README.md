## 🌍 English

A powerful Roblox script to freely customize your avatar (Headless, Korblox, Custom Assets) with Live Sync to other players!

### ⚙️ How to Use
Click the *Copy* icon at the top right of the code block below, then execute it in your Roblox executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/yuutaa7x/yuac/main/yuac.lua"))()
```

### 🌟 Key Features
- **Custom Assets ID:** Equip any accessories (Shirts, Hair, Hats, etc.) directly using Roblox Catalog IDs.
- **R15 & R6 Support:** Fully compatible with both classic R6 and modern R15 rigs.
- **Fake Headless & Korblox:** Includes precision position/rotation tweaks for Korblox legs.
- **Live Sync:** Your customized avatar will automatically sync and be visible to other players using YUAC in the same server!

## 🇮🇩 Indonesia

Script Roblox tangguh untuk mengustomisasi avatar secara bebas (Headless, Korblox, Custom Assets) yang tersinkronisasi langsung ke pemain lain!

### ⚙️ Cara Pakai
Pencet ikon *Copy* (Salin) di pojok kanan atas kotak kode di bawah ini, lalu jalankan di dalam *executor* Roblox milikmu:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/yuutaa7x/yuac/main/yuac.lua"))()
```

### 🌟 Fitur Utama
- **Custom Assets ID:** Pakai aksesoris apa saja langsung menggunakan ID dari Roblox Catalog.
- **R15 & R6 Support:** Sepenuhnya kompatibel dengan sistem pergerakan R6 klasik maupun R15 modern.
- **Fake Headless & Korblox:** Dilengkapi dengan fitur *Tweaks* untuk mengatur tinggi dan rotasi secara presisi.
- **Live Sync:** Avatar kerenmu akan otomatis terlihat oleh pemain lain di server yang juga menggunakan script YUAC!
